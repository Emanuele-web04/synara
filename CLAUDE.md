# Claude Code instructions

Read [AGENTS.md](AGENTS.md) for the shared Synara project contracts, task-specific references, verification rules, and completion criteria. It is the canonical repository policy for all coding agents.

Do not duplicate that policy here. Keep personal model preferences, pricing assumptions, and machine-specific delegation setup in operator configuration.

Two rules from that policy are broken often enough to repeat here: reuse the components, hooks, and functions that already exist instead of writing new ones from scratch, and size UI text with the font size chosen in Settings (`--app-font-size-ui*`), with titles as the only exception.
