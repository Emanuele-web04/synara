## Sources and constraints

- [T3 architecture at examined commit](https://github.com/pingdotgg/t3code/blob/d15210cd3da79f9a1a495a6309d912d76362a046/docs/internals/t3-connect.md).
- [Cloudflare API setup](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/get-started/create-remote-tunnel-api/) requires tunnel write and zone DNS write permissions, a configured zone, proxied CNAME and catch-all ingress. Multi-level subdomains may require advanced certificates: use a single generated label under the configured zone.
- [Cloudflare limits](https://developers.cloudflare.com/cloudflare-one/account-limits/) reviewed on 2026-09-28 list 1,000 tunnels/account and 25 replicas/tunnel. The selected account's pricing/contract must be checked at live setup. No assumption of unlimited/free tunnels. T3's billing assertion alone is not evidence of Synara's terms.
- [OpenAI prompting guidance](https://developers.openai.com/api/docs/guides/latest-model?model=gpt-6-astra#prompting-best-practices) consulted: continue authorized independent work, ask only for indispensable external inputs, size verification to change. No repository policy changes.
