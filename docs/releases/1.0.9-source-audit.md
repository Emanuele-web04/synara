## Durable documentation audit

- Native editor and connector availability is authoritative in shared feature policy, server gates, web policy, `BETA.md`, `docs/editor/intelligence.md` and `docs/mcp-connectors.md`. The promotion was already merged in #2002. Public editor, connectors, overview, Beta and shortcuts guides need matching Stable availability.
- `docs/providers.md` defines conditional Stop receipts, failed observations, isolated OpenCode login and cold discovery. Public provider and troubleshooting guides must retain those limits.
- `docs/core-concepts.md` defines local project logo precedence, worker action scope, visible goal startup and the continuous landing field. Public goal and customization guides need matching behavior.
- `MigrationBackup.ts` creates compressed snapshots and accepts old plain backups. Public recovery instructions must cover both formats and scratch-space requirements without promising a compression ratio.
- `docs/release.md`, desktop platform build configuration and Mac ZIP finalizer define macOS 13.0 / Darwin 22.0.0. Public requirements need the same minimum; macOS 15 packaged startup does not prove macOS 13 runtime.
- No migration file changed. Migration lineage and Windows runtime checks remain included because persistence and lifecycle behavior changed. Marketing inputs changed, requiring its separate build.
- The website's dirty operator checkout is preserved. Mirror and documentation updates follow tag push in an isolated checkout, with docs tests, lint and production build.

## Qualification boundary

Release preparation reuses the existing in-app and website changelog surfaces. Visible release text is authorized by the release task; no incidental layout or controls are introduced. Checkpoint, exact candidate SHA, commands, workflow attempts and public asset verification stay outside tracked release inputs. Full-suite, native signing/notarization, provenance, Defender and packaged startup are pending until the exact-tag workflow passes. Manual installation/upgrades, live providers/connectors and runtime on macOS 13 remain unqualified.
