## Durable documentation audit

- [Core concepts](../core-concepts.md) describes crash continuation exclusions, queue pauses, accepted sends, attachments, panel persistence and usage-limit cancellation. [Providers](../providers.md) documents ownership fences, verified Stop and provider/account limitations.
- [Interface languages](../internationalization.md) and the public customization guide cover System selection, Spanish, Beta-only Chinese, native permissions and guarded editor reload. Shared `betaFeatures.ts` retains `chinese-ui`; this release does not change gates.
- [SQLite reclamation](../sqlite-space-reclamation.md) covers the offline command, channel-specific paths, scratch space, cancellation, the rename commit point and Windows durability limits. The public desktop troubleshooting guide contains its operational instructions.
- Existing public customization, task recovery and desktop maintenance guides are extended for languages, usage-limit waits and offline compaction; Pi guidance is synchronized into the production website while retaining its older sections. Goals, editor, installation and shortcut guides retain their existing navigation. Source-evidence notes connect these additions; no disconnected guide is added.
- TestFlight announcements in this range describe separately qualified iOS builds; they do not qualify a desktop release or add desktop features.
- [Windows qualification](../windows-defender-1376.md) retains actual antivirus evidence and limitations. New Defender cloud requirements must pass on the exact candidate; previous success is not substituted.
