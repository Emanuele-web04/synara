## Beta baseline

The previous public Beta is `v1.0.2-beta.1`. Its successor also includes the
complete 1.0.2, 1.0.3 and 1.0.4 Stable ranges, not merely the 14 commits above.
The existing release entries retain their detailed accounting of those ranges.
Beta notes include the inline visuals introduced by #1874, which postdates
the previous Beta. They must also include the other durable changes: account selection in gateway
calls; thread-tab preference; Claude idle-resume behavior; nested Codex config
preservation; socket and provider-start recovery; full native conversation
snapshots replacing the recent-history cache; Hub navigation/permissions;
orphaned-session and unexpected-shutdown recovery; nonblocking maintenance and
FIFO handling; long-chat layout work; retained/restored browser tabs; Computer
Use clipboard, targeting and evidence improvements; provider setup/effort fixes;
sidebar order, first-message naming, queue, context-meter and accessibility polish.

Hubs were already available in the prior Beta. Its promotion to Stable is not
advertised as a newly added Beta feature. The older Beta's recent-history pager
was subsequently removed; current guides describe full native history and retain
paging only for imported provider history. No provider or model choice changes
are introduced by release preparation.

## Documentation and qualification boundaries

- The production website deploys from its separate repository.
  `apps/marketing` is its mirror in this repository; that mirror had omitted
  the last three Stable entries, which now match the in-app copy.
- Inline visuals and Connectors have dedicated guides, feature-navigation entries,
  overview/home links and source evidence. The existing navigation contract test
  includes both routes. Other affected workflows extend their existing guides.
- Connectors remain Beta-only. HTML visuals execute only on desktop; native
  components work in browser-hosted clients. Stable/Beta identities, state and
  updates stay separate. Diagnostics policy is unchanged.
- The inherited #1934 live smoke establishes one isolated Claude Sonnet 4.6
  response. Voice visibility tests do not establish live recording. SQL tests
  establish the affected query's output/performance, not universal server health.
- Local checks do not establish signed release artifacts. Exact-tag native
  packaging, provenance, startup, Windows Defender and public updater files must
  pass before this task reports either publication complete. Manual installed-app
  upgrades and Windows browser-download reputation require separate evidence.
