## Method and limits

- Tested each pinned source head in a detached isolated worktree with its own frozen lockfile. Shared workspace imports resolve to that source checkout, not to the combined branch. Tests use the repository Vitest scripts (`bun run test`), with source-relative test paths.
- Chromium 153 was installed separately; local browser tests use its explicit executable path. Full-app runs select relevant changed cases where feasible, preserving their assertions. Filtered cases and explicitly omitted inherited scopes are recorded in the JSON receipt.
- Dependency lifecycle scripts were disabled after node-pty header extraction failed with host `fchown EINVAL`; this is not a native dependency build or packaged-install qualification. No handwritten application logic was edited to make tests pass. Vite regenerated the Cline route tree, and source-owned screenshot tests refreshed their PNG evidence; those generated files were discarded before switching heads.
- Invocations have bounded harness deadlines (150 seconds for unit groups, 180 for browser groups). Memory/deadline retries used a separate source-head cache, 4 GiB Node heap and a 360-second invocation cap. Deadline, worker crash, skipped cases, and host failures remain visible; they do not establish a production regression or a successful feature.
- Mocked provider/OS bridges do not prove authenticated provider sessions, descendant cleanup, signed releases, macOS/Windows native behavior, or desktop installation/upgrade. Release logic tests do not choose between competing release proposals.
- Merge checks used `git merge-tree --write-tree` against freshly fetched declared bases. Stack PRs #1232, #1238, #1766, #1771, #1792, #1793, and #1835 target feature branches, not main. A stack can merge cleanly into a parent that itself cannot merge into main.
