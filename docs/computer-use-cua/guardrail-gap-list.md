## Spec consistency notes

One spec line still conflicts with the current tree state; the second was
resolved by the protocol-file update on 2026-09-17. Both are doc findings, not
code findings.

1. Acceptance criterion 7 says no "menu, or window frame tool is reachable by an
   agent." The 2026-09-17 audit update made `computer_invoke_menu` and
   `computer_set_window_frame` agent-facing under approval (`capability-audit-2026-09-16.md`
   "2026-09-17 update"; `computerTools.ts:142`–`:143`). The criterion text is
   stale; raw session and raw recording remain correctly excluded.
2. Acceptance criterion 6 expects the protocol file to document `cancel_input`,
   the ack fields, and the refusal taxonomy. Resolved 2026-09-17: the file now
   documents the handshake (`metadata`/`synara_native_revision`), the private
   `cancel_input` teardown method, the four cleanup-acknowledgement fields the
   host validates (`pid`, `input_admission_closed`, `cleanup_complete`,
   `pending_input`), the close-admission fail-closed rule, session/epoch
   carriage, and the three-value effect taxonomy
   (`packages/shared/src/cuaDriverProtocol.ts:12`–`:56`,`:88`–`:104`).
