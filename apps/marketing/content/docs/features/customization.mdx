Synara assumes you live in it for hours a day, so most of the surface is tunable.

## Theme pack editor

Tune the UI colors directly in settings. Shared theme tokens keep the sidebar, composer, transcript, and controls in sync, and terminal fonts and colors follow the active theme.

## Density and layout

UI density controls trade whitespace for information. Sidebar sections can be toggled (hide the standalone Chats list or the Workspace tab), the primary navigation can be reordered, and settings are deep-linkable from sidebar search.

## Shape the provider surface

- **Order**: drag providers into a custom order in settings — the composer, sidebar, and search palette follow it.
- **Favorites**: star models in the picker to float your picks above large Codex/Cursor/OpenCode catalogs.
- **Custom binaries**: point Synara at your own provider executable (a specific Codex or Claude Code install) instead of the default path.
- **Usage panels**: usage and pace appear in the chat Environment panel and settings for every enabled provider whose authenticated runtime exposes verifiable account data.
- **Update checks**: background provider CLI version checks can be disabled with the `enableProviderUpdateChecks` setting.

## Keyboard shortcuts

A settings panel covers shortcut exploration and customization; power users can go further with the [keybindings JSON file](/docs/reference/keyboard-shortcuts).

## Profile and activity stats

A local profile tracks your patterns: most-worked project, provider and model mix, active hours, and a token heatmap. It stays on your machine, like the rest of the workspace data.

## Releases, in the app

After an update, a one-time "What's new" dialog summarizes the release, and the full history lives under Settings → Release history. Update downloads show progress on the sidebar update button, installs self-verify after restart, and if an in-app update fails you can always fall back to the [download page](/install).

## Model presets and Mac icons in 0.9.0

The model picker groups providers into tabs and can star a model together with its reasoning effort. Select a saved combination to reuse both. Provider settings surface setup health; an installed executable alone is not proof of a connected, authenticated session.

The Mac app includes refreshed Liquid Glass icons. An alternate icon choice is reapplied after quitting and reopening; **Default** removes the custom override and returns to the bundled system-appearance behavior. Applying a custom icon needs a writable app bundle.

Profile Stats includes providers with real turns even when token telemetry is unavailable. Unknown token usage is not reported as a measured zero. Linux zoom shortcuts are handled by the desktop main process.

## Desktop refinements in 1.0.8

On Hyprland, the translucent shell uses compositor blur only when `decoration:blur:enabled` is confirmed enabled. Blur radius follows Hyprland settings. Other Linux sessions keep the existing window backing. Selected Linux icon artwork is installed separately for each app flavor.

## Project logos in 1.0.9

Projects use detected local favicon images across sidebar rows, pinned shortcuts, hover cards, search, pickers and Edit project previews. Your explicit emoji, icon or folder color takes priority; otherwise the fallback is a folder. Logos must stay inside the project and cannot execute scripts. Hub workers no longer offer Snooze or Hub actions, keeping delegated work reachable through its Hub.

The empty-chat ASCII field stays continuous beneath the composer's own surface. Its existing Appearance setting and reduced-motion behavior remain available.
